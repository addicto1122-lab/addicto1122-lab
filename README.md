## 🚀 Main Project

### MeetBack

여러 참가자의 귀가 시간과 막차 정보를 분석해  
안전하게 모일 수 있는 장소를 추천하는 서비스입니다.

- Kakao Local API 기반 장소 검색
- ODsay API 기반 대중교통 경로 및 막차 정보 조회
- 참가자별 안전 귀가 가능 여부 계산
- 평균 귀가시간과 편차를 반영한 장소 추천
- MyBatis / MySQL 기반 계산 결과 저장
- Naver Map 기반 이동 경로 시각화
- WebSocket / STOMP 기반 실시간 기능
- Redis 활용

## 🖥 Infrastructure

- Linux 서버 환경 구성

- NAT / Firewall / Routing 실습
